## How this file is maintained

`dashboard.py` reads the last row of each pulse log and rewrites the fingerprint line and the "Pulses" table. It does not invent numbers — a pulse with no fresh run just gets staler in the "Fresh?" column. "Blind spots" is hand-maintained; move a row out when an isolate lands and its log is registered above.

**Freshness.** ✅ last run ≤ 14 days ago, or `stage_fingerprint` unchanged since that run (nothing to re-measure). ⚠️ > 14 days **and** the framework hash moved. 🔴 protocol file exists but has no snapshot yet.

**Noise.** Same rule as the pulse logs: ≲5% median movement is noise, ≳15% is noteworthy. Runners auto-diff the new row against the last row with the same scena fingerprint.
