## Channel

**Handle:** `@Scena-python` (https://www.youtube.com/@Scena-python)

**Avatar:** `videos/finals/channel/avatar.png` (800 × 800; YouTube crops it to a circle)
**Banner:** `videos/finals/channel/banner.png` (2560 × 1440; title inside the 1546 × 423 middle every device shows)

**Description (English):**

> Scena is a Python framework for 2D games and creative graphics, built for
> learning and for making good games without the complications.
>
> You write the game: what is on the screen, how it moves, what happens when
> two things touch, what comes next. Each of these is a line or two that says
> what it means; Scena handles the loop, the drawing, the timers and the cleanup.
> A first program is three lines, and a whole game fits on one screen.
>
> Here: teasers, the tutorials built up step by step, and demos. Every video
> on this channel is 100% made with Scena.
>
> pip install scena
> Tutorial (English and Portuguese), API Guide and examples: links below.

## Before publishing

- Publish after 0.11.0 is on PyPI: the videos show the current engine, and
  `pip install scena` should install what they show.
- Upload as **Unlisted**, watch on a phone and a TV (code legibility, sound),
  then Public or Scheduled.
- After the first publish: the video link in the README and the Guia.
