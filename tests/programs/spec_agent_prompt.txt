HOW THE HARNESS RUNS THE PROGRAM (harness facts, not engine facts):
- The script runs top to bottom; its run() call is replaced by "begin the game"
  (the same startup run() does), then frames are stepped headless with fixed
  dt = 1/60 s unless a Scenario sets dt. random is seeded with Scenario.seed.
- After every frame each probe is evaluated; that is one Sample(frame, time,
  values). frame 1 = the first frame stepped. time = clock.time read after the frame.
- Input is delivered through the real window-input handlers at the start of the
  next frame (where a windowed run polls events).
- Program globals are visible to probes as attributes of p: p.group["ball"],
  p.roda, p.st.count, p.canvas, p.clock … (anything the script's namespace has,
  including names from `from scena import *`).
- PARAMS (dict) reaches the program; it reads PARAMS.get("key", default)
  (a program that never reads PARAMS ignores it).
- Media: a program's art loads from next to the script (its media/ folder) or,
  for a file headed "# harness: cwd=examples/media", from examples/media.
  You may list those folders to learn image sizes from file names only.
- click_widget(label) works for UI widgets (Button, Slider, CheckBox, ...) and for
  the options of an open Menu (by the option's text).
  A SpriteButton or any shape is clicked with click(x, y) at its position.
- key(name, frames=n): press is delivered at the start of the next frame,
  held for n frames, then released (the release is delivered one frame later).

Checks (each returns None on pass or a message):
  always(probe, pred, after=0, until=None)   never(probe, pred, ...)

Trace API inside custom(): t.samples (list of Sample(frame, time, values)),
  t.series(probe) -> [(frame, time, value)], t.values(probe), t.end(probe),
  t.at_frame(frame, probe), t.at_time(seconds, probe),
  t.press_frame(name, nth=0) / t.release_frame(name, nth=0) -> frame the nth
  press / release of key `name` ("R", "SPACE") or mouse button ("left") was
  delivered (presses and releases are counted separately),
  t.input_frame(prefix, nth=0) -> frame the nth input of a kind was delivered,
  counting every input of that kind in order: a key() step gives two "key"
  inputs (press, release), a click two "button" inputs (prefixes: "button",
  "key", "move", "scroll", "cell"), t.marks(name).
Probe values are frozen plain data: point-likes become (x, y) tuples, collections
become tuples, numbers become float. A probe that raises records a ProbeError value,
which fails any check that reads it.
close(a, b, tol) compares numbers / tuples approximately.
serial(obj) (import it from program_support) gives an object a per-run number:
use it to tell objects apart across frames, never id() (ids are reused once an
object is freed and differ between runs).
